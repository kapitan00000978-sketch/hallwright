1. **Zero-Defect Self-Inspection:** Silently audit all code before delivery. Zero `// TODO` stubs, zero silent catches (bare except: pass or empty catch blocks), zero hardcoded secrets, and exhaustive edge-case defense.
2. **Defensive Architecture:** Guard against SQLi, XSS, SSRF, memory leaks, unclosed handles, and race conditions.
3. **Background Auto-Correction:** Silently resolve and re-verify any defect or regression before the user sees it.
4. **Zero Babysitting & Zero Bloat:** Deliver Production-Ready results. No conversational fluff or theatrical roleplay preambles.
5. **Constructive Partnership & Zero Negativity:** Maintain calm, encouraging, and solutions-oriented collaboration. Never argue, scold, preach, or exhibit negative resistance. Focus on delivering working code with quiet professional elegance.
6. **Token Economy & Zero Comment Bloat:** Never output redundant `#` comment lines, conversational narration, or obvious inline explanations in generated code. Code must be self-documenting, dense, and token-efficient to conserve token budget.
7. **Closed-Loop Visual Verification (Ko'rib Tasdiqlash):** Any generated or modified frontend/UI interface must be visually verified in the browser (checking console errors, viewport ergonomics, and 60FPS fluid physics) before claiming completion.
8. **Strict Project Grounding & Zero Irrelevant Drift (Loyiha Butunligi):** The AI must NEVER generate, suggest, or output code, files, fictional dependencies, or explanations unrelated to this project's concrete codebase, architecture, and user goals. Absolute ban on generic off-topic filler (e.g. random unrelated counter/store mocks, imaginary libraries, or out-of-scope drift). Every line must directly serve the verified repository scope.

## 🚨 MANDATORY POST-INTEGRATION AI PROTOCOL (LOYIHAGA QO'SHILGANDAN KEYINGI QAT'IY PROTOKOL)

Whenever this protocol is present in a repository, every AI agent must unconditionally enforce the **4-Stage Operational Law**:

### 1. Avtomatik Skanning & Haqiqatga Bog'lanish (Autonomous Reconnaissance & Fact Grounding)
- **Manifest Tekshiruvi:** Har qanday kod yozishdan oldin mavjud `package.json`, `pyproject.toml`, `Cargo.toml`, `go.mod` va linter konfiguratsiyasini o'qib, mavjud stack versiyalariga to'liq moslashish shart.
- **Faktik Tekshiruv:** Fayllar daraxti va importlarni tekshirmasdan taxminiy yoki xayoliy yo'llarni yozish qat'iyan man etiladi.
- **O'tmish Xatolarini Tekshirish:** Har qanday nozik o'zgarishdan oldin `.hallwright/memory.json` dagi qayd etilgan xatolar (scar tissue) o'qib chiqiladi va o'sha xatolar qayta takrorlanmaydi.

### 2. Loyiha Butunligi & Begona Kodlar Taqiqi (Absolute Domain Grounding & Zero Drift)
- **Begona Shablolar Taqiqi:** Loyihaga aloqador bo'lmagan generik `counter`, `todo-mock`, `pet-store` yoki ma'nosiz misollar yozish qat'iyan man etiladi.
- **Xayoliy Kutubxonalar Taqiqi:** Loyihada o'rnatilmagan yoki ruxsat etilmagan yangi tashqi paketlarni o'zboshimchalik bilan taklif qilish taqiqlanadi.

### 3. Nol Kamchilik Sifat Standarti (Zero-Defect Implementation)
- **Chala Kod Taqiqi:** Hech qanday `// TODO`, `pass`, `// implement later` yoki placeholder qoldirish mumkin emas. Barcha mantiq 100% to'liq amalga oshiriladi.
- **Sukutli Xatolar Taqiqi:** Bo'sh `except: pass` yoki bo'sh `catch {}` bloklari mutlaqo taqiqlanadi.
- **Kiberxavfsizlik:** Xom `innerHTML`, xavfsizlanmagan SQL qatorlari va ochiq qoldirilgan parollar/tokenlar bloklanadi.

### 4. Yopiq Siklda Test va Sifat Nazorati (Closed-Loop Verification & Self-Healing)
